# Scientific Figure Quality Checklist

Run this checklist before returning a figure brief or image prompt.

## Scientific fidelity

- Are all named entities preserved correctly
- Are arrows, inhibition marks, and causal links supported by the source
- Are uncertainty and correlation represented honestly
- Did you avoid inventing measurements, sample sizes, or missing biology

## Figure choice

- Is this the right figure type for the available evidence
- Would a concept figure be safer than a quantitative chart
- Is the layout simple enough for a reader to parse quickly

## Visual design

- Is there a clear focal element
- Does panel order match the scientific story
- Are labels short, concrete, and domain-correct
- Is the color logic purposeful rather than decorative

## Prompt quality

- Does the prompt specify subject, composition, relationships, and annotation style
- Does it mention a scientific aesthetic instead of generic marketing language
- If the user needs an editable figure, did you provide a structured brief rather than only a raster prompt
